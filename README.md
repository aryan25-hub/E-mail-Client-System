# Email Client System

A modern, feature-rich email client built with React and Tailwind CSS to send and receive emails.

## Features
- 📧 Email Inbox management
- ⭐ Star important emails
- 🗑️ Archive and trash functionality
- ✏️ Compose new emails
- 🔍 Search emails
- 📁 Folder organization

## Installation Process

1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Technologies Used
- React
- Tailwind CSS
- Lucide React Icons
